# 科目一模拟题练习 · Driving Theory Quiz

**[在线体验 →](https://anna123123123-creator.github.io/driving-quiz/)**

免费开源、纯浏览器运行的驾照科目一模拟题练习工具。内置 15 道真实交通法规单选题，答题后立即显示对错和简要解析，随机顺序练习，记录正确率。不联网、不上传答题记录。

![screenshot](screenshot.png)

**⚠️ 仅供练习参考，题库内容以实际考试大纲和官方最新题库为准。**

## 试用方法

直接用浏览器打开 `index.html`，或用静态文件服务器跑起来：

```bash
python3 -m http.server 8000
```

## 题库

15 道单选题，覆盖信号灯含义、让行规则、恶劣天气限速、故障停车、记分标准、酒驾标准等常见考点，每题附简要解析。
